# Privacy Policy — DSP Platform Web 1.0.0

**Effective:** 2026-07-22

## Summary

- Session preferences and optional beta feedback may be stored in the browser (`localStorage`).
- Feedback is redacted for tokens/JWTs and must not include research envelopes, portfolio holdings, or API secrets.
- No third-party analytics SDK is required for Web 1.0.0.
- Operators may configure separate production logging; avoid PII in client feedback.

This document is an operational summary and does not replace jurisdictional legal review.
