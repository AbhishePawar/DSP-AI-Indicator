# RS-001 … RS-010 — Constitutional Research Standards

| Field | Value |
|---|---|
| **Status** | **MANDATORY** |
| **Effective** | 2026-07-28 |
| **Violation class** | **Research Report Validation FAIL** (also fails Architecture Review) |
| **Authority** | [RESEARCH_STANDARDS.md](RESEARCH_STANDARDS.md) · [adr/ADR-RS-001-research-standards.md](adr/ADR-RS-001-research-standards.md) |
| **Companions** | [CORE_VALUES.md](CORE_VALUES.md) (HOW) · this catalog (WHAT) |

**Core Values (CV)** govern *how* the platform behaves.  
**Research Standards (RS)** govern *what* every production research report **MUST** contain.

Missing required section or mandatory field (without honest **Data unavailable.** /
**Unable to calculate.** where permitted by CV) = **FAIL**.

Governance only — does not change engines, scoring, APIs, models, boundaries,
or deterministic behaviour.
