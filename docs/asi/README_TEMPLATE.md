# Package README Template (ASI-005)

| Field | Value |
|---|---|
| **Version** | `1.0.0` |
| **Status** | Active |
| **Authority** | ASI-005 Documentation Excellence |

Copy this structure for every `packages/*/README.md`.  
Describe **current** implementation only. Mark futures explicitly in §12.

```markdown
# <import_name>

## 1. Package Purpose
## 2. Responsibilities
## 3. Package Status
## 4. Public API
## 5. Package Structure
## 6. Dependencies
## 7. Architecture Notes
## 8. Usage Examples
## 9. Testing
## 10. Governance
## 11. Limitations
## 12. Future Extensions (future only)
```

Long historical READMEs may keep detail under an **Appendix** after the twelve sections.
Permanent index → [PACKAGE_DOCUMENTATION_MATRIX.md](../PACKAGE_DOCUMENTATION_MATRIX.md).
