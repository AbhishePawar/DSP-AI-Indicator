# User Guide — DSP Platform Web 2.0.0-rc (Commercial RC)

## Overview

DSP AI Indicator presents research intelligence: company analysis, knowledge graph, deterministic research copilot, reports, and session portfolio demos.

## Closed beta / RC access

If your deployment enables closed beta (`NEXT_PUBLIC_CLOSED_BETA`):

1. An administrator must approve your invite (email or username).
2. Sign in with that identity.
3. A beta banner appears at the top of the app.
4. If you see “Invitation required”, contact your operator.

## Workflows

1. Sign in and open **Dashboard**
2. Acknowledge the research disclaimer on first report generation
3. Run **Company Analysis**
4. Explore **Research** workspace and ratings / explainability / valuation transparency sections
5. Optionally use **Portfolio Intelligence** (session demo)
6. Export from analysis/research export surfaces
7. Send structured feedback via the floating **Feedback** control (acknowledge before submit)

## Research Mode

Research Mode is enabled. The product does **not** show BUY/SELL/HOLD or Target Price UI unless compliance flags unlock them. Review Evidence, Confidence, Methodology, and Limitations on every analysis.

## Trust

Never paste API secrets, portfolio holdings, or raw research envelopes into feedback forms.
