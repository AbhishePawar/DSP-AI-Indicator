# Epic V2.0 Sprint 7.2 — Shared Research Workspace

**Web:** `2.0.0`

## Mission

Collaborative Shared Research Workspace for organizing, comparing, bookmarking, and reviewing existing DSP research. Presentation only — no Research Engine changes.

## Surfaces

- `/advisor/team/shared-research` — Overview dashboard + quick actions
- `/advisor/team/shared-research/library` — Library · filters · recent/saved/pinned
- `/advisor/team/shared-research/collections` — Create / rename / delete / move / favorite
- `/advisor/team/shared-research/compare` — Compare 2–5 companies (existing fields only)
- `/advisor/team/shared-research/bookmarks` — Bookmark · pin · favorite · recently viewed
- `/advisor/team/shared-research/activity` — Activity feed buckets

## Trust

Reuses demo research envelopes only. Never modifies or regenerates conclusions, Evidence, Confidence, Methodology, or Limitations.

## Enable

`NEXT_PUBLIC_ADVISOR_DEMO=true`
