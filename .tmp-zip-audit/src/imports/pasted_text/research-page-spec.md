==================================================
RESEARCH PAGE — CHAT-FIRST + INFORMATION-RICH
==================================================

The Research Page is the CORE PRODUCT EXPERIENCE.

It should feel like using ChatGPT for serious equity research.

The interaction model should be:

USER QUESTION
↓
DSP RESPONSE
↓
VISUAL EVIDENCE / INFOGRAPHIC
↓
USER FOLLOW-UP
↓
DSP RESPONSE
↓
DEEPER VISUAL EVIDENCE

The user should be able to keep asking questions naturally without leaving the research page.

Do NOT make the Research Page look like a traditional stock dashboard.

The conversation is the primary interface.

==================================================
CHATGPT-LIKE EXPERIENCE
==================================================

The user should feel:

"I can ask DSP anything about this company."

Example:

USER:
"How strong is TCS financially?"

DSP:

"Financially, the business appears strong based on its profitability,
balance sheet and cash-generation profile."

Then immediately provide compact visual evidence.

[ Revenue Growth ]
████████████████
+XX%

[ ROCE ]
██████████████
XX%

[ Net Debt ]
Very Low

[ Free Cash Flow ]
Strong

Then:

"Would you like me to examine the balance sheet in more detail?"

USER:
"Yes, show me the balance sheet."

DSP responds inside the SAME conversation.

No page reload.

No separate dashboard navigation required.

==================================================
COLORFUL INFOGRAPHICS
==================================================

Although the overall product should remain minimal and premium,
the research responses should use COLORFUL INFORMATION VISUALIZATION.

Do not make the interface monochrome.

Use color strategically to make financial information easier to understand.

Examples:

Revenue growth → blue/teal
Profitability → green
Risk → amber/orange/red
Valuation → purple/indigo
Cash flow → teal
Debt → neutral/blue
DSP Indicator → distinctive DSP accent

Colors must communicate meaning.

Do not use random decorative colors.

==================================================

Examples:

User:

==================================================
DO NOT OVERLOAD THE CHAT
==================================================

Important:

The answer should remain conversational.

Do NOT produce:

huge tables
20 metric cards
giant dashboards
long paragraphs

Instead:

SHORT ANSWER

+
1–3 RELEVANT VISUALS

+
OPTIONAL "VIEW MORE"

The user can then ask the next question.

==================================================
PROGRESSIVE INFORMATION
==================================================

Use progressive disclosure.

Example:

DSP:

"Cash generation has remained strong."

[FCF TREND CHART]

[View cash-flow details]

If the user clicks:

View cash-flow details

then expand the detailed analysis inside the conversation.

Do not navigate away unnecessarily.

==================================================
DSP SHOULD EXPLAIN THE VISUALS
==================================================

Never show a chart without context.

Example:

DSP:

"Free cash flow has remained positive across the period,
which supports the company's ability to fund operations internally."

[FCF CHART]

This combination is important:

CONVERSATION
+
EXPLANATION
+
VISUAL EVIDENCE

==================================================
INTERACTIVE INFOGRAPHICS
==================================================

Where useful, allow users to interact with visualizations.

Examples:

- hover for exact value
- change time period
- expand chart
- switch between revenue/profit/FCF
- compare peers
- view source
- view calculation

But interactions must remain simple.

Do not turn charts into complicated analytical software.

==================================================
RESEARCH PROGRESS
==================================================

During research generation, the chat should progressively show activity.

Example:

DSP

✓ Identified security

✓ Verified financial data

✓ Reviewed profitability

✓ Reviewed balance sheet

◐ Assessing valuation...

Then the actual answer begins appearing.

Avoid generic:

"Loading..."

Use meaningful research stages.

==================================================
MULTI-TURN CONTINUITY
==================================================

The conversation must maintain context.

Example:

USER:
"How is profitability?"

DSP:
answer + chart

USER:
"What about debt?"

DSP:
answer + debt infographic

USER:
"Compare that with Infosys."

DSP:
comparison infographic

USER:
"Now calculate valuation."

DSP:
valuation response

The UI must make this feel like ONE continuous research conversation.

==================================================
CHAT INPUT
==================================================

The bottom input should feel similar to ChatGPT:

Ask DSP about this company...

Possible suggestions:

"How strong is the balance sheet?"
"Is valuation attractive?"
"What are the biggest risks?"
"Show me the financial trend"
"Compare with peers"

Suggestions should disappear naturally once the conversation starts.

The input should remain easily accessible.

==================================================
VISUAL HIERARCHY
==================================================

Priority:

1. User question
2. DSP answer
3. Visual evidence
4. Source/evidence details
5. Optional deeper analysis

Never allow the infographic to overpower the conversation.

The user should always understand:

WHAT DID I ASK?
WHAT DID DSP ANSWER?
WHAT EVIDENCE SUPPORTS IT?

==================================================
OVERALL FEEL
==================================================

The Research Page should feel like:

ChatGPT
+
Bloomberg-style information density
+
modern editorial design
+
colorful financial infographics.

But do NOT copy Bloomberg, ChatGPT, or any other product visually.

Create an original DSP identity.

The key principle:

"CHAT FIRST. DATA WHEN NEEDED. VISUAL WHEN USEFUL."

Keep the interface low-key and simple,
but make the actual research information visually rich.
