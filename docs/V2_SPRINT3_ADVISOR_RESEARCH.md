# Epic V2.0 Sprint 3 — Advisor Research Workspace

**Web:** `2.0.0`

## Mission

Organize existing DSP research into reusable collections for client servicing. Presentation only — no Research Engine changes.

## Surfaces

- `/advisor/research` — Library (recent, saved, favorites, reports, pinned, search)
- `/advisor/research/collections` — Create / Rename / Archive (session demo)
- `/advisor/research/compare` — 2–5 company compare on demo envelopes
- `/advisor/research/notes` — Pinned / Private / Client / Meeting / Findings
- `/advisor/research/timeline` — Activity timeline
- `/advisor/research/bookmarks` — Favorites / Recent / Pinned / Tags

## Trust

Reuses demo DSP research envelopes. Does **not** modify conclusions, generate recommendations, or alter Evidence · Confidence · Methodology · Limitations.
