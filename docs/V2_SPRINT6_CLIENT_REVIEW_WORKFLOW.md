# Epic V2.0 Sprint 6 — Client Review Workflow

**Web:** `2.0.0`

## Mission

Guided end-to-end client review connecting clients, research, model portfolios, meetings, tasks, and presentation packs. Presentation only — no persistence, no calendar, no Research Engine changes.

## Surfaces

- `/advisor/reviews` — Upcoming / In Progress / Completed / Archived
- `/advisor/reviews/active` — Checklist · timeline · prep · summary · actions
- `/advisor/reviews/dashboard` — Workflow overview
- `/advisor/reviews/templates` — Initial Consultation → Custom

## Trust

Reuses existing DSP demo research summaries and presentation/portfolio links. Never alters Evidence · Confidence · Methodology · Limitations.

`NEXT_PUBLIC_ADVISOR_DEMO=true`
