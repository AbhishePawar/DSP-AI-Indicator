# User Guide — DSP Platform Web 1.0.0

## Overview

DSP AI Indicator presents research intelligence: company analysis, knowledge graph, deterministic research copilot, reports, and session portfolio demos.

## Workflows

1. Sign in and open **Dashboard**
2. Run **Company Analysis**
3. Explore **Knowledge Graph** and **AI Copilot**
4. Optionally use **Portfolio Intelligence** (session demo)
5. Export from **Reports**
6. Send structured feedback via the floating **Feedback** control

## Research Mode

Research Mode is enabled. The product does **not** show BUY/SELL/HOLD or Target Price UI. Review Evidence, Confidence, Methodology, and Limitations on every analysis.

## Trust

Never paste API secrets, portfolio holdings, or raw research envelopes into feedback forms.
