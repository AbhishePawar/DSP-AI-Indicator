# Epic V2.0 Sprint 7.4 — Team Review & Assignment

**Web:** `2.0.0`

## Mission

Collaborative Team Review & Assignment Workspace for coordinating client reviews, ownership, progress, and discussion using existing DSP advisor demos. Presentation only.

## Surfaces

- `/advisor/team/shared-reviews` — Lane overview + dashboard
- `/advisor/team/shared-reviews/board` — Assignment board (drag + keyboard move)
- `/advisor/team/shared-reviews/discussion` — Session discussion notes
- `/advisor/team/shared-reviews/timeline` — Activity timeline
- `/advisor/team/shared-reviews/progress` — Completion & readiness
- `/advisor/team/shared-reviews/activity` — Activity feed

## Trust

Reuses existing Client Review workflows and linked research/portfolio demos. Never modifies research conclusions, portfolio calculations, Evidence, Confidence, Methodology, or Limitations.

`NEXT_PUBLIC_ADVISOR_DEMO=true`
